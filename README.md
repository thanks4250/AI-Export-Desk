# AI Export Desk — 우리 회사 수출 폴더

AI를 **친절한 수출 담당 직원**처럼 쓰는 폴더입니다. 일은 채팅으로 시키고, 결과는 전부 이 폴더에 쌓입니다. 채팅은 사라져도 폴더는 남습니다 — 바이어·메일·조사·회사 지식이 한곳에 모이고, 나중에 CRM으로 옮길 수도 있습니다.

> AI무역아카데미 10강 「수출초보기업 해외진출전략」 실습 자료 · 엄한결

## 처음 한 번 (10분)

1. **이 폴더를 내려받아 압축을 풉니다.** 이름은 바꿔도 됩니다(예: 「OO식품 수출 폴더」).
2. **Claude 데스크톱 앱의 Cowork**(유료 요금제)에서 새 작업을 열고, **보내기 전에 이 폴더를 먼저 고릅니다.** 입력창 위에 폴더(FOLDER) 표시가 보여야 합니다. 새 작업을 열 때마다 이렇게 합니다.
3. **메일을 연결합니다 (필수).** 커넥터(연결) 설정에서 Gmail이나 Outlook을 연결하세요. 바이어와 주고받은 메일을 AI가 찾아 정리합니다.
4. **캘린더도 연결하면 좋습니다 (권장).** 바이어 미팅·샘플 마감을 함께 기록합니다.
5. 회사소개서·카탈로그가 있으면 `받은자료/` 에 넣고(없으면 홈페이지 주소만 있어도 됩니다) 이렇게 보냅니다.

```
시작
```

AI가 대시보드를 먼저 띄우고, 회사 이름·홈페이지·주력 제품·관심 나라·메일 보내는 사람을 차례로 물어봅니다(처음 한 번만). 그 답으로 **우리 회사 위키**와 후보국 비교를 만듭니다. 대시보드 홈의 「처음 할 일」을 하나씩 따라 하면 됩니다.

## 이렇게 말하세요 — 부하 직원에게 하듯

| 하고 싶은 일 | 채팅에 이렇게 |
|---|---|
| 바이어 찾기 | `베트남 하노이에서 연락할 만한 베이커리 체인 5곳 찾아 줘` |
| 바이어 넣기 | `ABC Trading 바이어로 넣어 줘. 전시회에서 명함 받았어` (명함 사진을 같이 끌어다 놓으면 더 좋음) |
| 파일 정리 | 파일을 끌어다 놓고 `정리해 줘` — 무엇이든 알아서 제자리로 |
| 메일 쓰기 | `ABC에 첫 소개 메일 영어로 써 줘` · `ABC가 보낸 메일 풀어 주고 답장 써 줘` |
| 보낸 뒤 | `ABC 메일 보냈어` — 기록하고, 고쳐 보낸 점을 배웁니다 |
| 검수 | 내가 쓴 글을 붙이고 `보내도 돼?` — 중요한 것만 한 번 짚어 줍니다 |
| 메일 가져오기 | `메일 가져와 줘` — 바이어와 주고받은 메일을 찾아 기록에 넣음 |
| 회사 정보 | `거래 조건에 리드타임 4주로 넣어 줘` · `우리 회사 정보 고쳐 줘` |
| 가르치기 | `앞으로 메일은 더 짧게 써 줘` |
| 상태 바꾸기 | `ABC는 샘플 보냈어` · `XYZ는 그만할래` |
| 조사 | `태국 냉동 베이커리 시장 알아봐 줘` · `베트남 수입 규정 확인해 줘` |
| 장부 칸 추가 | `바이어에 결제조건 칸 추가해 줘` |
| 확인 | `검증해 줘` — 숫자·관세·인증을 다시 찾아 맞는지 가림 |
| 엑셀·CRM | `장부 엑셀로 뽑아 줘` · `CRM으로 내보내 줘` |
| 화면 | `대시보드` (띄우기) · `갱신` (고쳐 두기만) · `폴더 열어 줘` |
| 이어 하기 | `이어서` |

AI가 일을 마치면 「다음에 뭐 할까요?」 선택지를 띄웁니다. 누르기만 해도 됩니다.

## 쓸수록 우리 회사에 맞춰집니다

- **우리 회사 위키** (`회사/`) — 회사 개요·제품·거래 조건·인증·자주 받는 질문. 한 번 알려 준 가격·MOQ·납기는 위키에 남아 다음부터 다시 묻지 않습니다.
- **일하는 방식** (`회사/05 일하는 방식.md`) — 메일 문체, 자주 쓰는 표현, 하지 말 것. 고쳐 달라고 한 것이 두 번 보이면 규칙으로 올라가고, 칸마다 줄 수에 상한이 있어서 넘치면 AI가 합치고 버립니다. 쌓일수록 길어지는 게 아니라 정수만 남습니다.
- **바이어마다 「이 바이어는」** — 그 바이어의 언어·말투·관심사를 5줄로 기억합니다.

## 대시보드

- 일은 채팅에서, 대시보드는 **보기 전용**입니다. AI가 일할 때마다 고쳐 둡니다.
- 열어 둔 화면은 저절로 바뀌지 않습니다. 위쪽 **↻ 새로고침**을 누르면 최신이 보입니다(파일로 연 화면은 창을 다시 볼 때 저절로 새로고침).
- 「자료」 탭에서 파일을 찾고, 폴더 위치를 복사해 탐색기로 열 수 있습니다.

## 대화는 짧게, 기억은 폴더에

이 폴더는 기억이 대화가 아니라 **폴더에** 있으므로, 새 대화를 열어도 잃는 것이 없습니다.

- 한 대화에 너무 많은 일을 몰아넣으면 느려지고 사용량도 빨리 닳습니다. 큰 일이 끝나면 새 대화를 여는 습관이 좋습니다(하루 한 대화도 좋아요).
- 새 작업을 열고 → 이 폴더를 고르고 → `이어서` 라고만 보내면, AI가 `진행기록.md` 를 읽고 하던 일을 이어 갑니다.
- 대화가 정말 길어지면 AI가 한 번 알려 줍니다.
- 바이어마다 대화를 따로 열 필요는 없습니다. 바이어 이야기는 그 바이어 폴더에 다 모입니다.

## 폴더 안에 있는 것

| 이름 | 무엇 |
|---|---|
| `받은자료/` | 아무거나 던지는 곳. 정리하면 비워집니다 |
| `회사/` | 우리 회사 위키와 회사소개서·카탈로그 원본 |
| `시장/나라/` | 조사 보고서 |
| `바이어/나라/회사/` | 바이어마다 기록·메일·견적·자료 |
| `장부/` | `바이어.csv` · `연락기록.csv` — 엑셀로 열립니다. `현황.json`·`대시보드 갱신.py` 는 AI가 씁니다 |
| `보관/` | 그만둔 바이어·조사, 오래된 기록 (지우지 않고 보관) |
| `대시보드.html` | 한눈에 보는 화면 |
| `진행기록.md` | 지금 하던 일·다음 할 일(인수인계)과 날짜별 기록 |
| `AGENTS.md` · `CLAUDE.md` | AI가 읽는 작업 규칙. 고치지 않아도 됩니다 |

## 꼭 기억할 것

- AI 결과는 **초안**입니다. 시장 수치·관세·인증은 공식 자료로, 바이어의 구매 의사는 직접 연락해서 확인하세요.
- AI는 메일을 직접 보내지 않습니다. 초안을 확인하고 보내는 건 사람입니다.
- 계좌·여권번호 같은 개인정보는 넣지 마세요.
- AI의 기능과 요금제는 자주 바뀝니다(2026년 10월 기준으로 만든 자료입니다).
