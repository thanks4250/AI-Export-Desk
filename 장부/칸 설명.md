# 장부 칸 설명

장부는 엑셀로 열리는 CSV 파일 두 개입니다. AI가 채우고, 대시보드는 이 장부를 그대로 보여 줍니다. 칸을 더 만들고 싶으면 채팅에 「바이어에 ‘결제조건’ 칸 추가해 줘」처럼 말하세요.

## 바이어.csv — 바이어 한 곳이 한 줄

| 칸 | 뜻 | 채우는 법 |
|---|---|---|
| 바이어ID | B001, B002 … | AI가 차례로 붙임. 바꾸지 않음 |
| 회사명 | 영문 정식 이름 | 필수 |
| 현지어 이름 | 현지 글자 이름 | 알면 |
| 나라 | 한국어 나라 이름(베트남·태국…) | 필수 |
| 도시 | 하노이·방콕 … | 알면 |
| 유형 | 수입·유통사 / 체인 본사 / 매장 / 에이전트 / 온라인 / 기타 | |
| 단계 | 후보 → 연락함 → 답장 옴 → 샘플 → 협상 → 계약 (그만두면 보관) | 명함만 받았거나 찾기만 한 곳은 「후보」. 우리가 메일·전화를 보낸 뒤에 「연락함」 |
| 등급 | A·B·C — 우리 제품과 맞는 정도 | AI가 이유와 함께 |
| 담당자 · 직함 · 이메일 · 전화 | 주 연락 상대 | **확인된 것만.** 모르면 「확인필요」 |
| 웹사이트 · 주소 | | 확인된 것만 |
| 특징 | 어떤 회사인지, 왜 우리와 맞는지 한두 줄 | |
| 다음 할 일 · 다음 할 일 날짜 | 이 바이어에게 다음에 할 일 | |
| 폴더 | 이 바이어 폴더 경로 (바이어/나라/회사명) | AI가 |
| 등록일 · 출처 | 언제, 어디서 알게 됐나(전시회 명함·검색·메일 등) | |

담당자가 여러 명이면 주 담당자만 장부에 두고, 나머지는 그 바이어 폴더의 `기록.md` 맨 위 「사람」 칸에 적습니다.

## 연락기록.csv — 주고받은 일 하나가 한 줄

| 칸 | 뜻 |
|---|---|
| 날짜 | YYYY-MM-DD |
| 바이어ID · 회사명 | 누구와 |
| 종류 | 메일 보냄 / 메일 받음 / 메일 초안 / 통화 / 미팅 / 샘플 / 견적 / 메모 |
| 내용 | 한두 줄 요약 |
| 파일 | 관련 파일 경로(있으면) |
